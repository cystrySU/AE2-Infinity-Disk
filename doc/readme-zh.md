# AE Infinity Disk

AE Infinity Disk 是一个面向 Minecraft 1.19.2 的 [Applied Energistics 2](https://appliedenergistics.github.io/) 附属模组。

本模组为 AE2 提供了一枚拥有近乎**无限容量**和**无限物品类型上限**的 ME 存储磁盘，主要面向后期或超大规模 AE 网络的存储需求。

---

## 模组简介

在常规 AE2 游戏中，玩家往往会在后期遇到以下痛点：

- 单个驱动器容量有限，需要大量堆叠磁盘与驱动器；
- 物品类型数量受限，杂物过多会导致不可存放；
- 网络规模庞大后，存储读写性能和流畅度可能受到影响。

AE Infinity Disk 通过提供一枚高端的“无限磁盘”来缓解这些问题：

- 实际使用中无需再为容量和物品类型上限操心；
- 尽可能在保持性能的前提下支持极大规模的存储网络；
- 通过配置文件提供一定的平衡调整空间，便于融入不同整合包。

---

## 主要特性

- **无限容量**：可以存储任意数量的物品，无固定上限。
- **无限物品类型**：支持任意数量的不同物品类型，不受类型数量限制。
- **性能优化**：内部使用缓存、脏标记与轻量级 NBT 读取等机制，以适应大型 AE 网络下的高频访问场景。
- **可配置平衡**：可通过配置文件调整能量消耗、软上限等参数，以满足不同整合包和服务器的平衡需求。
- **多语言支持**：内置多种语言翻译，包括简体中文、英文、日文、韩文等。

## 安装说明

1. 安装 Minecraft 1.19.2，并配置对应版本的 Forge（建议 43.5.0 或更高）。
2. 安装 Applied Energistics 2，对应版本不低于 12.9.5。
3. 下载与当前 Minecraft 版本匹配的 AE Infinity Disk 模组 JAR 文件。
4. 将该 JAR 文件放入游戏目录下的 `mods` 文件夹中。
5. 启动游戏，确认模组列表中已正确加载 Applied Energistics 2 与 AE Infinity Disk。

如在整合包或服务器环境中使用，请遵循整合包维护者或服务器的相关发布与更新流程。

## 配置说明

模组的通用配置文件位于：

`config/ae_infinity_disk-common.toml`

常用配置项如下：

| 配置项                      | 默认值      | 说明                                                         |
|----------------------------|------------|--------------------------------------------------------------|
| `enableDynamicEnergyDrain` | `false`    | 是否启用动态能量消耗（随存储物品数量增加而提升能耗）。     |
| `baseIdleDrain`            | `1.0`      | 基础空闲能量消耗（AE/t）。                                  |
| `maxIdleDrain`             | `512000.0` | 空闲能量消耗上限（AE/t），默认软上限为 512k AE/t。         |

一般建议：

- 若希望“无限磁盘”更具成本与后期感，可适当提高 `baseIdleDrain` 和 `maxIdleDrain`；
- 若偏向休闲或创造模式体验，可保持较低能耗甚至关闭动态能量消耗；
- 在服务器环境中，请与服主沟通后再调整相关配置，以避免服务器负载异常。

修改配置后通常需要重启游戏或服务器使配置生效。

## 更新日志（摘要）

若需完整、英文版的更新日志，请参考项目根目录的 `README.md` 中的 Changelog 小节。本节为中文摘要说明。

### 1.1.2

- 移除遗留的内部调试指令，不再对普通玩家可见。
- 本次更新为小型维护版本，不涉及玩法与平衡改动。

### 1.1.1

- 将配置项 `enableDynamicEnergyDrain` 的默认值调整为 `false`，即默认关闭动态能量消耗。
- 为空闲能量消耗增加软上限：`maxIdleDrain` 默认为 `512000.0` AE/t（512k AE/t），以避免在极端网络规模下出现过高能耗。
- 优化配置加载与应用流程，确保旧存档在添加新配置项后能够正常运行。

### 1.1.0

- 引入缓存层以加速内部存储查询，显著降低在大型网络中的交互开销。
- 新增脏标记机制，仅在内容发生变化时才触发必要的写入操作。
- 优化 NBT 读写流程，在保存/加载大量物品时减少性能消耗。
- 调整无限磁盘的 GUI：简化背景、减少多余贴图使用，提升界面清晰度与加载性能。
- 对界面文本启用字符串缓存，降低高频打开界面时的分配与渲染压力。

### 1.0.0

- AE Infinity Disk 首个公开版本发布。
- 新增无限 ME 存储磁盘物品，为 AE2 网络提供近乎无限的存储容量与物品类型上限。
- 提供基础能量消耗相关配置项，便于整合包或服务器进行平衡调整。
- 内置多语言本地化文件，支持多种常见语言，并与 Applied Energistics 2 基本实现联动。
